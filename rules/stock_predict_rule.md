# A股个股数据分析规则

本插件是**纯数据层**：`api.py` 只负责抓取公开行情数据并计算客观技术指标，
**不做任何打分、不预测方向、不给区间、不给置信度**。所有分析判断由你（Agent）完成。

## 触发场景

- "分析一下 600519 / 贵州茅台"、"XX 明天怎么看 / 会涨吗"
- "XX 的技术面 / 资金面 / 消息面怎么样"
- "帮我复盘一下 XX"、"出一份自选股日报"
- 用户在侧边栏点击"让 Agent 分析"后发来的 `【A股数据】...` 消息

## 工具与用法

| 工具 | 用途 | 何时用 |
|---|---|---|
| `stock_predict` | 一次拿全九大数据块（行情/技术指标/盘中/资金流/大盘/情绪/新闻/两融/数据可用性） | 用户要完整分析时**首选** |
| `stock_quote` | 轻量行情（价格、涨跌、均线位置、RSI） | 只要一句当前状态时 |
| `stock_analyze` | 按单一维度返回数据（tech/fund/sentiment/market/news） | 用户只问某个维度时 |
| `stock_daily_report` | 批量拉多只股票的数据摘要 | 日报/复盘/定时任务 |

**执行顺序**：先确认 6 位代码（股票名需先映射，如贵州茅台=600519，不确定就问用户）→ 调工具拿数据 → 自己分析 → 输出。

## 分析框架（你自己做，不要复述数据）

拿到数据后按以下维度思考，**只输出结论和关键依据，不要把原始数据整段抄给用户**：

1. **技术面**：均线排列（MA5/10/20/60 多空排列、价格位置）、MACD（金叉死叉、柱体变化）、RSI（超买超卖）、BOLL（位置与开口）、量能（量比、换手率变化）、ATR（波动幅度，用于评估风险）。
2. **资金面**：近 5~10 日主力净流入方向与强度、是否与股价背离（价涨资金流出=警惕）、两融余额变化。
3. **情绪面**：涨停家数与最高连板（市场赚钱效应）、该股所在行业是否在涨停行业分布前列。
4. **大盘环境**：上证近 5/20/60 日趋势，判断个股是顺势还是逆势；大盘走弱时个股独立行情难度大。
5. **消息面**：新闻标题里是否有业绩、订单、监管、股东减持、行业政策等实质信息。**注意：新闻只有标题和时间，没有正文，不要臆测内容**。

## 盘中 / 非盘中的分析口径（重要）

工具返回的 `session_state` 决定分析口径，**必须区别对待**：

- `trading` / `lunch_break`（`is_intraday=true`）：有 `intraday` 块，包含现价、VWAP、日内位置、盘中量比、30 分钟动量、振幅。
  - 盘中数据是**未完成的当日 K 线**，技术指标（MA/MACD/RSI）基于**上一交易日收盘**计算，两者要分开描述，不要说成"今天 MACD 金叉"。
  - 盘中量比已按已交易分钟数折算，可直接与日常量比比较。
  - 明确告知用户当前是盘中数据，结论可能随收盘变化。
- `pre_open` / `closed`（`is_intraday=false`）：`intraday` 为 null，只有收盘数据，按常规盘后分析。
- `no_data`：数据缺失，如实说明。

## 数据可信度

工具返回 `data_quality`，逐项标注每个数据源状态：

- `ok`：正常
- `none`：该股票确实没有此类数据（如无解禁），**不是故障**
- `error`：抓取失败

**有 `error` 项时必须在回答中说明**"X 数据本次获取失败，该维度判断依据不足"，不得假装有数据、不得用其他维度凑数掩盖。

## 输出规范

1. **先说结论**（一句话倾向 + 主要理由），再展开依据。
2. 每个维度给 1~2 条**关键依据**，引用具体数值（如"MA5 27.96 低于 MA20 28.80，短期均线压制"）。
3. 给出**主要风险点**（至少 1 条）。
4. **必须保留免责声明**（工具输出已自带，不得删减或改写）。
5. 明确说明这是基于公开数据的分析，非投资建议。

## 禁止

- **禁止**给出确定性买卖指令（"明天必涨，满仓买"）。
- **禁止**编造工具未返回的数据（尤其是新闻正文、机构评级、目标价）。
- **禁止**把 `data_quality` 里的 `error` 说成正常。
- **禁止**删除或弱化免责声明。
- **禁止**在盘中把未完成的当日 K 线当作已完成 K 线做技术指标判断。

## 注意

- 数据来自公开免费接口，有延迟与限流可能，插件已内置缓存与多源降级。
- `stock_predict` 一次调用约 10 秒（9 个数据源），批量分析多只股票请用 `stock_daily_report`，不要循环调 `stock_predict`。
- 同花顺全市场资金流接口极慢（60s+），插件不会自动降级到它，资金面数据缺失时按中性处理。
